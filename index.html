MFML Tutor

A guided introduction on how to approach singular value decomposition (SVD) problems.

Understanding the Main Goal:

Using SVD, a matrix A can be re-written in the form: A = UΣVᵀ.

This is made of up of three matrices:

  • U : representing the matrix of left singular vectors
  • Σ : representing the matrix of singular values
  • VT: representing the matrix of right singular values

    • NOTE: Vᵀ changes the input coordinates, Σ scales directions, and U maps them into the output space.

    Example Walkthrough: 

    A = [3  1]
    [1  3]

    We will find the SVD of this matrix step by step.

    1. Calculating ATA

    First, find the tranpose A, then multiply Aᵀ by A. This example is symmetric, so Aᵀ = A. 

    AᵀA = [3 1][3 1]
    [1 3] [1 3]
    
    = [3×3 + 1×1   3×1 + 1×3]
    [1×3 + 3×1   1×1 + 3×3]

    = [10   6]
    [ 6  10]

    Question: Why is the top-right entry 6?

    Give me a hint

    Take the dot product of the two columns of A.

    Show full explanation

    The calculation is 3×1 + 1×3 = 6. We are multiplying the first row of AT with the second column of A

    2. Find the singular values

    Find the eigenvalues of AᵀA, by solving for the det(ATA - λI) = 0:

    det(AᵀA − λI) = 0

    (10 − λ)² − 36 = 0

    λ1 = 16
    λ2 = 4

    Question: What are the singular values for the matrix?

    Hint?

    Singular values are the nonnegative square roots of these eigenvalues.

    Show the singular values

    σ₁ = √16 = 4 and σ₂ = √4 = 2.
