# MFML AI Tutor

Purpose: 
An AI tutor to help students learn and understand concepts from MFML (Mathematical Foundations of Machine Learning) at RPI better. 

# Project Goals:
- Help students feel more confident in understanding MFML concepts
- Incorporate feedback from professors and students to tailor the tutor to fit the needs of RPI students
- 
# Features:
- Sample notes to refresh knowledge on the main topics that used/covered within a specific lesson
- Guided walkthrough of how to perform SVD on a matrix from start to finish (computing the different matrices and singular values)
- Practice Problems (Ranging from simple to challenge) to practice applying the concepts and feel more confident solving the related problems
